Buatkan program Java GUI menggunakan Swing dengan konsep Object Oriented Programming (OOP) untuk simulasi antrian bank menggunakan prinsip FIFO (First In First Out).

Ketentuan umum:
- Gunakan JFrame sebagai window utama.
- Gunakan struktur data Queue dengan implementasi LinkedList.
- Setiap elemen antrian terdiri dari nomor antrian (auto increment) dan nama pelanggan.

Struktur program (OOP):
- Class utama (GUI) untuk menangani tampilan dan interaksi pengguna.
- Data antrian disimpan dalam Queue.
- Pisahkan logika pengelolaan antrian dan tampilan.

Fitur program:
- Input nama pelanggan (JTextField)
- Tombol:
  1. "Ambil Antrian" → menambahkan data ke queue
  2. "Tampilkan" → menampilkan seluruh isi queue
  3. "Panggil" → mengambil dan menghapus elemen pertama (FIFO)

Tampilan GUI:
- Gunakan BorderLayout
- Bagian atas: input dan tombol
- Bagian tengah: JTextArea untuk menampilkan antrian
- Gunakan JScrollPane
- Gunakan font Monospaced pada JTextArea

Validasi:
- Nama tidak boleh kosong (gunakan JOptionPane)
- Jika queue kosong saat "Panggil", tampilkan pesan error

Fitur suara:
- Saat tombol "Panggil" ditekan:
  - Tampilkan popup:
    "Nomor X atas nama Y, silakan ke loket"
  - Gunakan Text-to-Speech:
    - Untuk Linux: gunakan espeak melalui ProcessBuilder
    - Program menunggu proses selesai (process.waitFor())

Tambahkan method:
- updateTextArea() → untuk memperbarui tampilan antrian
- speak(String text) → untuk menjalankan TTS

Gunakan kode yang rapi, terstruktur, dan mudah dipahami.
Sertakan method main untuk menjalankan program.
